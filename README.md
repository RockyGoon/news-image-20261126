# One Day in the News — 26 November 2026

A morning-edition newspaper front page summing up 26 November 2026's world
news in one image: 20 stories, all dated or first reported on 26 November
2026, as reported by 09:00 WIB. Lead: the 100th Macy's Thanksgiving Day
Parade postponed as a nor'easter bears down on New York.

`main.py` (Python 3.13, standard library only) validates `entry.png`
(1024×1024, under 1 MiB) and writes an exact copy to the output directory.
